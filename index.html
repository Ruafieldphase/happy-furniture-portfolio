오프라인 파일 받기

    태블릿 오프라인 재생 안내

    • 아이패드 (Safari): 내려받은 HTML 파일은 파일 앱 미리보기에서 자동 재생이 차단돼요. 지금 Safari에서 공유(□↑) → 홈 화면에 추가로 추가해 실행하면 인터넷 없이도 자동 재생됩니다.
    • 레노버 탭 · 안드로이드 (Chrome): 메뉴(⋮)에서 홈 화면에 추가 또는 앱 설치를 권장해요. 내려받은 파일을 열 때는 ‘HTML 뷰어’가 아닌 Chrome으로 열기를 선택해 주세요.
    • 노트북 · PC: 내려받은 workshop-offline.html을 Chrome이나 Edge로 열면 바로 재생됩니다.
